# SiaoVPlay

SiaoVPlay 是一款 Windows 本地优先的跨语言智能播放器。它面向已经找到海外视频、但缺少可靠简体中文字幕的中文用户。

产品围绕三个层级组织：

```text
观影
→ 按需理解
→ 可选学习
```

当前已完成第一阶段桌面基础：

- Tauri 2、React、TypeScript 和 Rust 桌面工程。
- 独立 SQLite 项目库与播放位置恢复。
- 本地视频探测和 H.264/AAC 兼容播放版本。
- 媒体未变化时复用探测结果，暂停或继续播放不会重复运行媒体探测。
- 导入视频后自动生成本地项目封面，已有项目会自动补齐。
- 从应用相邻目录自动发现 FFmpeg，不要求预先设置环境变量。
- Windows 文件选择、`Ctrl+O` 和媒体路径启动。
- 原片与兼容版本播放、项目重新定位和安全删除。

第二阶段正在实现：

- 从公开 HTTPS 媒体直链或点播 M3U8 保存受控本地副本；拒绝内网地址和未经检查的重定向。
- URL 导入不读取浏览器 Cookie、账号内容或用户代理配置，支持取消并清理未完成下载。
- 从播放器选择 UTF-8 SRT、WebVTT 或视频内嵌文本字幕。
- 导入前显示时间轴预检结果；图片字幕轨会明确标记为暂不支持。
- 独立字幕轨、不可变字幕版本和稳定字幕段。
- 字幕文件、项目版本与媒体指纹变更检查。

当前仓库仍处于开发阶段，尚未提供正式安装包。YouTube 导入、四语种转写、字幕翻译、按需理解和学习功能尚未进入可用版本。

开发构建可以通过文件选择器导入视频，也可以传入本地媒体路径：

```powershell
siao-vplay.exe "D:\Media\example.mp4"
```

## 基本边界

- 本地媒体优先。
- 不提供片源。
- 不绕过登录、会员或 DRM 限制。
- 不把播放器扩张为视频剪辑工作台。
- 项目暂不提供自有云模型服务。
