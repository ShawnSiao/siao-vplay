# SiaoVPlay

SiaoVPlay 是一款 Windows 本地优先的跨语言智能播放器。它面向已经找到海外视频、但缺少可靠简体中文字幕的中文用户。

**当前为开发版本，尚未提供通过公开 Beta 验收的安装包。** 版本与渠道以 [release.json](release.json) 为准；下载只认 [GitHub Releases](https://github.com/ShawnSiao/siao-vplay/releases) 中对应版本的产物与哈希。

原创代码使用 [MIT](LICENSE)，第三方内容保留原许可，见 [第三方说明](THIRD-PARTY.md)。开发与构建步骤见 [贡献指南](CONTRIBUTING.md)，安全问题见 [报告方式](SECURITY.md)。

目标平台为 Windows 10 22H2 x64 和 Windows 11 x64；正式支持以对应候选的双系统验收结果为准。「本地优先」不代表所有 AI 处理离线：字幕与选定关键帧可能交给所选 API 服务或 Codex 的模型服务，费用与账号由使用者自行提供。

产品围绕三个层级组织：

```text
观影
→ 按需理解
→ 可选学习
```

默认界面专注观影。剧情解释、人物表达理解、查词和学习卡片只在用户主动操作后出现。

## 当前能力

### 导入与播放

- 导入本地视频，或从公开 HTTPS 直链、点播 M3U8、YouTube 和 X 公开单视频建立本地项目。
- 不读取浏览器 Cookie、账号内容、用户级 yt-dlp 配置或插件。
- yt-dlp 无法读取公开 X 媒体时，可主动同意向清单所列解析服务发送帖子 ID；默认不启用该回退。可通过 `SIAOVPLAY_X_PUBLIC_RESOLVER` 更换解析服务，接收地址改变后需要重新确认，视频文件仍从 X 媒体地址直接下载。
- 拒绝私网地址、播放列表，以及已知需要登录、订阅或付费的内容。
- 不兼容的媒体会生成独立播放版本，不修改原片。
- 保存项目、播放位置、媒体关系和自动生成的项目封面，重启后可以恢复。
- 在「环境配置 → 存储」中分别管理应用数据与数据库、URL 导入视频、播放缓存、默认字幕导出位置，以及默认视频与报告保存位置。
- 托管数据跨目录迁移会先检查容量、复制并校验，再切换到新位置；应用数据在重启后切换，旧目录默认保留。

### 字幕与翻译

- 导入 UTF-8 SRT、WebVTT 和视频内嵌文本字幕。
- 对字幕时间轴和来源变更执行预检，原文字幕保留为不可变版本。
- 使用本地 Whisper 对英语、泰语、日语和韩语原声生成带词级时间戳的原文字幕。
- 将上述四种语言以及其他语言的原文字幕翻译为简体中文。
- 翻译可使用环境配置中保存的 API 服务，也可选择 Codex 或手动提示词交接。准备材料后需确认实际接收地址、模型、字幕版本和范围，才会发送。
- API 翻译分批保存结果；失败或重启后可重试未完成批次，已完成批次会复核后复用。服务配置改变时需要重新准备并确认，可能产生服务费用。
- 结果通过任务、版本、范围和完整性检查后写入独立中文草稿，不覆盖原文。结构检查不代表译文意思完全准确，仍需人工抽查。
- 提供逐句修正、全局替换、整轨偏移、历史恢复和选段重译。

### 理解、学习与交付

- 在当前播放点按需回看最多 3 分钟、40 条字幕和 6 张受控关键帧，生成带证据引用的事实与可能解读，不读取播放点之后的材料。
- 主动生成截至当前进度或已确认剧透的完整视频总结；长视频按字幕稳定分块，支持取消、重启恢复、历史结果和结构化证据校验。
- 当前理解与视频总结均可使用内置提示词、可复用个人模板和单次补充要求；不可修改的材料范围和结果结构始终优先。
- 视频总结先准备本地材料，再显示接收服务、实际字幕版本、范围和关键帧时间点；确认后才发送。重试重新核对清单，材料校验失败时需重新准备。Codex 调用使用 OpenAI 登录与默认模型，不读取用户的模型服务配置，仍需联网。
- 场景理解与学习查询同样先准备材料，再确认实际发送清单；API 和 Codex 均需确认后执行。理解清单可展开查看分析要求，关键帧默认关闭。更改接收方、服务版本或任务材料会使旧确认失效。
- API 任务支持取消排队与中止本机请求连接；已发送内容可能已经由服务处理，取消不能撤回已发送材料。
- 将总结导出为本地 Markdown 报告、相对链接关键帧和 SHA-256 完整性清单；明确区分视频陈述、证据、AI 推导和待外部验证内容。
- 在当前字幕语境中查词，保存带场景截图的学习卡片；词语、短语、整句和卡片可使用匹配语言的 Windows 本机声音朗读。
- 导出原文、简体中文或双语 SRT／WebVTT。
- 生成烧录简体中文字幕或双语字幕的独立 MP4；任务支持取消、中断恢复和版本确认。

## 运行时与安装包

当前 Windows 安装包只包含 SiaoVPlay 产品本体、内置资源目录清单和必要说明。FFmpeg、FFprobe、yt-dlp、whisper.cpp、VAD、转写模型和 GPU 运行时都不进入安装包。

构建 NSIS 安装包不需要预先准备第三方运行时或模型：

```powershell
npm run desktop:build
```

脚本使用 `CARGO_TARGET_DIR` 和 `SIAOVPLAY_ARTIFACT_DIR`，未设置时使用仓库内被忽略的构建与产物目录，也可显式传入路径。维护者本机继续将缓存和候选包放在已登记的非系统盘目录。构建前检查版本、Tauri 资源白名单和内置目录清单，生成后保存哈希与源码清单。隔离安装与文件清单检查使用 `tools/verify-app-only-install.ps1`，不会由构建命令自动安装到正在使用的应用。

组件来源与固定基线：

- Whisper 模型：[whisper.cpp 模型说明](https://github.com/ggml-org/whisper.cpp/blob/master/models/README.md)；`small` 与 `base` 的大小和 SHA-256 固定在本地运行时目录实现中。
- FFmpeg：[BtbN FFmpeg Builds](https://github.com/BtbN/FFmpeg-Builds)；按需版本固定在内置资源目录清单中。
- `yt-dlp`：[官方 Releases](https://github.com/yt-dlp/yt-dlp/releases)；按需版本固定为 `2026.08.19`。

## 候选版本状态

当前开发版本包含当前场景理解、视频总结、Markdown 报告、提示词模板和 Windows 本地朗读。候选包用于验收，不代表正式发布。

候选安装包暂未作为公开 Release 提供，原因如下：

- 安装包尚未进行代码签名。
- 当前候选的 Windows 10 和 Windows 11 干净环境安装、启动与卸载验收尚未全部完成。
- 双系统完整主流程、真实四语言与长视频人工质量、外部试用尚未全部完成。

Beta 可以明确标注为未签名；正式稳定版要求有效签名与时间戳。签名不保证新文件立即获得 SmartScreen 信誉。下载页须说明真实状态，不建议关闭系统防护。

开发版本仍支持通过 `SIAOVPLAY_RUNTIME_DIR`、`SIAOVPLAY_MODEL_DIR`、`SIAOVPLAY_FFMPEG` 或 `SIAOVPLAY_FFPROBE` 使用受控的本机调试资源。该方式不属于普通用户安装流程。

开发构建也可以传入本地媒体路径：

```powershell
siao-vplay.exe "D:\Media\example.mp4"
```

## 基本边界

数据库升级前保留独立备份，备份失败时停止升级；旧程序拒绝打开更高版本数据库。恢复步骤及备份范围见 [数据库升级与恢复](RECOVERY.md)。

- 本地媒体优先，不提供片源或自有云模型服务。
- 不绕过登录、会员、DRM 或平台访问限制。
- 只处理用户拥有权利或明确获准处理的媒体。
- 向外部 Agent 发送材料前显示接收服务和发送范围，不暴露本机媒体路径。
- SiaoVPlay 不是视频剪辑器；复杂时间轴、剪辑和专业字幕审校继续由 SiaoCut 承担。
